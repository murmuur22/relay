# Updater reference terminal — design audit (Unreleased)

Surface: Monitor primary; Operate secondary. Scope: desktop Updater browser and independently served/embedded updater only. The latest user refinement restores monochrome accents and replaces the reference wordmark with a small functional header; the ordinary Relay desktop is unchanged.

Composition: approximately 70/30 at reference-sized desktop widths, cream hairline rules, near-black subtly textured terminal, left-aligned small “Relay updater” header. A real depth-tested Three.js TorusKnotGeometry feeds a shaded character pass, bounded at 180×120 cells, with circular dotted coordinate guides; decorative slogans have been removed. The right rail prioritizes real job events, large monochrome artifact percentage, phase, bytes and a 40-character bar. Release selection, notes, password/explicit consent and history remain available in the scrollable rail; narrow containers stack rather than adopting a generic card dashboard.

Typography: two deliberate self-hosted OFL families, Silkscreen Bold and Share Tech Mono Regular. Percentage numerals are pixel; the smaller percent sign uses the technical family for legibility. Original upstream license bytes, pinned google/fonts URLs/commit, source/output SHA-256 and full-font WOFF2 conversion tooling are recorded in src/assets/font-sources.json and distributed notices. No runtime CDN or private reference fonts.

Slop self-audit: 0/10. No tech gradient, default indigo, feature-tile grid, accent-card strip, unearned blur, icon toppers, center-stack, default system typography or wrong-surface hero. The oversized number is specifically requested and earned by real artifact bytes, not an invented performance/statistic. This is a self-audit, not independent reviewer approval.

Honesty: 68% captures are visibly synthetic route-mocked visual snapshots rendered by real Three.js, not installation evidence. There is no invented node/CDN/version/speed/ETA/latency. Percentage means received artifact bytes; idle/unknown totals show —. Received 100% during verifying does not become update success. Stale state stays labelled and mutation authority remains disabled. Original-owner, CSRF, current password, one-use target authority and exact embedding policy were not changed.

Executed evidence: both builds; all 38 Chromium updater UI cases; 8 unit/progress cases; 13 root updater frontend cases; 15 updater backend cases; 72 Python updater cases; compiled HTTP/cookie/CSRF/font smoke; real disposable HMAC broker installation and readiness-failure matching-state rollback; embedded auth-loss/restart/sign-in/demotion/teardown. Targeted WebKit font/layout/missing-WebGL smoke passed, not physical Safari GPU qualification. Exact font/notice bytes passed both actual unsigned local archives and Chromium loading probes using extracted packaged assets. Linux browser bytes were packaged on macOS; no Linux execution, signed release, production install or full unrelated root suite is claimed.

Screenshot inspection: reference-sized 1100×726, actual floating/narrow desktop window, 390×844 mobile, verifying, success, idle, reduced motion and no-WebGL states were captured and inspected. The functional 3D pose/shading and freely licensed fonts approximate the reference; they are not a static traced facsimile. Mobile stacks into a long scrollable monitor. Reference-sized and smaller floating rails scroll for release operations/history. Existing optional ordinary-desktop font 404s remain preexisting and excluded.

Historical design evidence above was obtained at local source version 0.6.4 before delivery work; the earlier unsigned archives predate the minimal-header refinement. The design is now grouped with runtime presentation delivery in the 0.6.5 candidate. Current clean-source/archive/hosted evidence belongs in TEST_REPORT, not those historical packaging claims. The [unprivileged delivery bridge](updater-ui-delivery.md) requires fresh installation or a separately qualified manual web-only bootstrap; ordinary runtime updates never replace broker/web API/configuration/units. No privileged self-updater or production change is added.
